# TikTok / Reel — „3am Fever Panic" 🌙

Marketing package dla pierwszego TikToka promującego **Spokojny Rodzic**.

## 🎯 Cel

Pokazać emocjonalny problem (panika rodzica w nocy z gorączką dziecka) + rozwiązanie (apka mówi co robić bez googlowania) w **25 sekund**.

## 📁 Co tutaj jest

```
marketing/tiktok-3am-fever/
├── STORYBOARD.md              ← plan filmu, 8 scen, hook, alternatywne wersje
├── audio-scripts.md           ← voice-overy PL/EN/DE/FR/ES (do nagrania)
├── CAPCUT-GUIDE.md            ← krok-po-kroku montaż w CapCut
├── scenes/                    ← 8 PNG mockupów (1080×1920) gotowe do importu
├── preview-contact-sheet.png  ← wszystkie 8 scen w jednym obrazie (podgląd)
├── generate-scenes.mjs        ← regen scen jeśli storyboard się zmieni
├── generate-preview.mjs       ← regen contact sheet
└── README.md                  ← ten plik
```

## 🚀 Quick start (30-60 min od zera do publikacji)

1. **Przeczytaj** `STORYBOARD.md` (5 min) — zrozum koncept
2. **Otwórz** `preview-contact-sheet.png` — zobacz jak wyglądają wszystkie 8 scen
3. **Nagraj voice-over** z `audio-scripts.md` (15 min, telefonem)
4. **Otwórz** `CAPCUT-GUIDE.md` i podążaj krok-po-kroku (30 min)
5. **Publikuj** na TikTok we wtorek-czwartek 19:00-21:30 CEST

## 🎁 Wartość tego pakietu

Bez tego pakietu: musiałbyś sam wymyślić storyboard, scenografię, voice-over script i montaż. Łatwo **5-10 godzin** roboty.

Z tym pakietem: ~45 min nagrywania (głos + screen recording) + 30 min montażu = **~1.5h od zera do gotowego TikToka**.

## 🔁 Reuse dla kolejnych klipów

Po pierwszym klipie:
1. Skopiuj folder: `cp -r tiktok-3am-fever tiktok-vaccination-reminder`
2. Edytuj `STORYBOARD.md` na nowy scenariusz
3. `node generate-scenes.mjs` — wygeneruje nowe sceny
4. Reszta procesu identyczna

**Pomysły na kolejne klipy**:
- „Vaccination reminder" — „Bilans 9-miesięczny? Wpadłaś z głowy?"
- „Sleep tracking" — „Ile naprawdę spało Twoje dziecko ostatnią noc?"
- „Doctor visit prep" — „Co powiedzieć pediatrze — gotowa lista"
- „Multi-language pride" — „Polski + niemiecki + francuski + hiszpański = 1 apka"
